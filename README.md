# Полезные блоки
Команда: «Магнит» (группа И9-23Г, команда № 1)
 
Участники:
- Шишина Анастасия
- Шафеева Сафия
- Фанасян Сергей
 
Цель проекта: разработать модификацию Minecraft с блоком «Магнит»,
который притягивает выпавшие предметы в радиусе 5 блоков.

Магнитный блок — новый функциональный блок, способный притягивать к себе любые свободно лежащие в игровом мире предметы (ItemEntity) в радиусе 5 блоков.

Рабочее имя объекта (lower_snake_case): magnet_block\
Пространство имен проекта (MODid): examplemod

## Свойства объекта «Магнит»
- **Прочность (Strength):** 3.0f — соответствует ванильному железному блоку, требует усилий для разрушения.
- **Сопротивление взрывам (Explosion Resistance):** 6.0f — блок устойчив к случайным подрывам криперов.
- **Требование к добыче (requiresTool):** Добывается строго киркой. При поломке голыми руками предмет блока уничтожается без выпадения.

Обоснование стоимости: Магнит — это сложный и ценный механизм, притягивающий предметы. Высокая стоимость рецепта (целый железный блок в центре и 7 железных слитков вокруг) логически обуславливает его высокую физическую прочность (3.0f). Использование редстоуна в схеме символизирует «электромагнитную» природу притяжения.
